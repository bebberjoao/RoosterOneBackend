# Checklist de CRUD

## Criação

- [ ] DTO de criação validado.
- [ ] Service realiza persistência corretamente.
- [ ] Controller expõe a rota esperada.
- [ ] Banco recebe os dados corretamente.

## Leitura

- [ ] Buscar por ID funciona.
- [ ] Listagem retorna dados esperados.
- [ ] Filtros e query params são documentados.

## Atualização

- [ ] Atualização parcial ou completa está bem definida.
- [ ] Campos inválidos são rejeitados.
- [ ] Regras de negócio são preservadas.

## Remoção

- [ ] Exclusão respeita regras aplicáveis.
- [ ] Registro removido é tratado de forma consistente.
- [ ] Logs e auditoria são considerados quando necessário.
