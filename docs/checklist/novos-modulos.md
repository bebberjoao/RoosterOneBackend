# Checklist para criação de novos módulos

## Antes de começar

- [ ] Definir o domínio e objetivo do módulo.
- [ ] Identificar entidades, relacionamentos e regras de negócio.
- [ ] Verificar se há módulo semelhante para reutilizar padrão.
- [ ] Definir DTOs de entrada e saída.

## Implementação

- [ ] Criar controller, service, module e DTOs.
- [ ] Registrar o módulo no módulo principal.
- [ ] Definir rotas REST consistentes.
- [ ] Atualizar Prisma com os modelos necessários.
- [ ] Documentar o módulo na wiki.

## Revisão

- [ ] Validar nomeclatura e organização.
- [ ] Confirmar tratamento de exceções.
- [ ] Revisar regras de negócio e impacto em outros módulos.
