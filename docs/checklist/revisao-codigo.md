# Checklist de revisão de código

## Geral

- [ ] O código segue o padrão do projeto.
- [ ] Nomes de variáveis e métodos são claros.
- [ ] A lógica de negócio está no service correto.
- [ ] O controller está enxuto e sem regra de negócio.

## Segurança

- [ ] Não há exposição indevida de dados.
- [ ] Campos sensíveis não são expostos em retorno.
- [ ] Regras de autorização foram consideradas.

## Qualidade

- [ ] O código é legível e bem organizado.
- [ ] Há consistência com DTOs e Prisma.
- [ ] O impacto em outros módulos foi analisado.
