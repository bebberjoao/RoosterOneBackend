# ADR-001 - Uso de NestJS como framework principal

## Contexto

Era necessário escolher um framework backend que oferecesse estrutura modular, boas práticas e integração com TypeScript.

## Problema

O projeto precisava de uma base escalável para crescer com organização e previsibilidade.

## Alternativas avaliadas

- Express sem estrutura formal;
- Fastify com configuração manual;
- NestJS com arquitetura modular.

## Decisão tomada

Adotar NestJS como framework principal.

## Justificativa

O NestJS oferece modularização, injeção de dependência, boas práticas de organização e alinhamento com o ecossistema TypeScript.

## Consequências

- estrutura mais organizada;
- melhor manutenção;
- fácil expansão para novos módulos.
