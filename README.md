# Rooster One API

Backend do Rooster One — NestJS + Prisma + PostgreSQL.

Documentação completa: [docs/README.md](docs/README.md).

## Início rápido

```bash
npm install
npm run prisma:generate
npm run prisma:migrate
npm run start:dev
```

Detalhes de instalação, configuração e execução: [docs/operations/](docs/operations/).
